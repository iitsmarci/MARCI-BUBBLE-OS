# Collega Apple Calendar

1. Apri il file `.env` in questa cartella con Blocco note.
2. Dopo `ICLOUD_USERNAME=` scrivi l'indirizzo email del tuo Apple Account.
3. Dopo `ICLOUD_APP_PASSWORD=` incolla la password specifica per app che hai appena creato.
4. Salva il file.
5. Nel terminale, dentro questa cartella, esegui `npm run dev`.
6. Apri l'indirizzo che comparirà sullo schermo e ricarica la pagina.

La password resta soltanto nel file `.env` del tuo computer. Non inviare mai quel file, né la password, in chat o via email.

Per scollegare Apple Calendar, cancella la password dal file `.env` e salva. Se hai bisogno di invalidarla, puoi revocarla dal tuo Apple Account.
